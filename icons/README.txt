Icon Files Required

Please add the following icon files to this directory:

- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)  
- icon128.png (128x128 pixels)

You can create these using:
- Online tools like https://www.favicon-generator.org/
- Image editors like Photoshop, GIMP, or online editors
- Any icon generator that supports PNG format

The icons should represent the Shopify Project Manager extension.
You can use a simple design with an "S" or shopping bag icon, or any design that fits your preference.
